# Icon and brand asset notes

## Rizvisions

- The Rizvisions eye and wordmark were supplied by Rizvisions.
- The About Riz icon uses the supplied eye artwork without added gloss or decorative effects.

## Supplied app assets

- Safari, System Settings, Parker, and Trash use the image assets supplied for V9.5.
- Finder, Messages, Photos, Notes, Terminal, and folder artwork are bundled only to simulate a personal macOS desktop.
- `EXTRACT_MACOS_SYSTEM_ICONS.command` can replace supported files with the exact application resources installed on the site owner’s Mac.
