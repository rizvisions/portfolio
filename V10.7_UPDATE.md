# Update to V10.7.0

V10.7 is the stabilization and safe-iteration release.

## What changed

- Added automated browser regression coverage at 1440×900 and 1280×800.
- Protected every desktop app launch, Photos defaults and chronology, mixed photo/video Desktop placements, posterless videos, Terminal input, Notes sizing, marquee selection, minimized temporary Dock apps, and stock-media hydration.
- Added automated source checks for missing local assets, leaked Supabase secrets, migration guidance, and version drift.
- Added pull-request quality checks with browser traces, screenshots, and videos retained when a test fails.
- Added repository rules for safe future changes.
- Corrected the Admin recovery message so a missing `media_placements` table points to the V10.5 placement migration.

## Supabase

No migration is required for V10.7.0.

## Deployment

Review and test the feature-branch preview. Merge the approved pull request into `main`; GitHub Pages will deploy `rizvisions.com` from the canonical repository.
