# V10.8 — Rizvisions Archive

V10.8 gives the Photos app a clearer point of view: it still feels native to the desktop, but the content now reads as a personal archive rather than a generic photo browser.

## What changed

- Added a Rizvisions Archive summary with live media counts and date range.
- Grouped the All Photos view into newest-first daily moments.
- Redesigned Featured as an editorial memory strip.
- Added hover/focus titles and capture dates without cropping source media.
- Expanded the gallery information panel with useful capture and file metadata.
- Preserved portrait, landscape, and square proportions for desktop media.

## Compatibility

- Existing Supabase media and placement data is reused without modification.
- Existing local desktop layouts remain intact.
- No Supabase migration is required.

## Verification

Static integrity checks and Playwright browser coverage run at 1440 × 900 and 1280 × 800 before merge.
