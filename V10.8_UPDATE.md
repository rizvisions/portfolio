# V10.8 — Media refinement

V10.8 makes Photos and individual media windows feel more native, direct, and predictable.

## What changed

- Kept All Photos as the immediate, newest-first working surface without a branded banner.
- Fixed image visibility and first-click video opening in the Photos grid.
- Kept Featured restrained and close to the V10.7 Photos layout.
- Rebuilt the Photos library as a uniform square grid so portrait and landscape media never overlap.
- Replaced the dark gallery with a white, breathable viewer that always contains the full frame.
- Moved media information into a draggable floating panel so it never shrinks the media.
- Surfaced camera, lens, exposure, aperture, ISO, file, video, and GPS metadata when available, including an OpenStreetMap preview for geotagged media.
- Added editable location, frame-rate, and codec metadata in Admin for media that cannot expose it automatically.
- Standardized desktop media as square Polaroid cards with a subtle hover lift.
- Opened individual media at its true ratio and locked resizing to that ratio.
- Restored the exact pre-fullscreen window dimensions after Escape and stabilized video compositing to prevent landscape playback jitter.
- Hid individual-media titlebars until hover and clarified the muted state.
- Centered traffic-light symbols and optically normalized the Calendar icon.

## Compatibility

- Existing Supabase media and placement data is reused without modification.
- Existing local desktop layouts remain intact.
- No Supabase migration is required.

## Verification

Static integrity checks and Playwright browser coverage run at 1440 × 900 and 1280 × 800 before merge.
