# Update from V10 to V10.5

## 1. Run the migration once

In Supabase:

1. Open **SQL Editor**.
2. Click **New query**.
3. Open `supabase/migrate-v10.5.sql` from this package.
4. Copy the entire file into Supabase.
5. Click **Run query**.

A destructive-operation warning is expected because the migration safely recreates Rizvisions policies and triggers. It does not delete your uploaded media.

The final result shows `placement_table_ready`. Existing uploads remain intact.

## 2. Deploy the website

Upload everything inside `rizvisions-macos-v10.5` to the root of `rizvisions/portfolio`, replacing the current files.

Wait for GitHub Pages to finish and hard-refresh `https://rizvisions.com`.

## 3. Use Admin normally

Open `https://rizvisions.com/admin/`.

Each asset can now be placed in:

- Photos, with a Collection and optional Featured status
- Desktop
- Selected Work, inside a chosen project folder

The same asset can appear in several destinations without being uploaded more than once.
