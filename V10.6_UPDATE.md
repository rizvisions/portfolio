# Update to V10.6

## 1. Supabase

Run `supabase/migrate-v10.6.sql` once in **SQL Editor → New query → Run**.

A successful run returns `media_metadata_ready` with the number of existing media rows. No media is deleted.

## 2. GitHub Pages

Upload everything inside the `rizvisions-macos-v10.6` folder to the root of the `rizvisions/portfolio` repository, replacing existing files.

## 3. Refresh

After the Pages deployment is green, hard-refresh `rizvisions.com` with **Command + Shift + R**.

Use `https://rizvisions.com/?hello=1` to replay the new intro animation.
