# Update to V10.6.3

This is a front-end-only hotfix.

## Supabase

Do **not** run another SQL migration. V10.6.3 does not change the database.

## GitHub

Upload everything inside the `rizvisions-macos-v10.6.3` folder to the root of the `rizvisions/portfolio` repository, replacing existing files.

Wait for GitHub Pages to deploy, then hard refresh the live site.

## Fixed

When a Desktop placement was a video with no generated poster, the desktop renderer called a helper that no longer existed. That JavaScript exception aborted the full desktop media render, so photos disappeared too whenever one of those videos was enabled.

V10.6.3 renders posterless video thumbnails safely and does not let one media item prevent the others from appearing.
