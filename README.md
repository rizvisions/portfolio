# Rizvisions Desktop — first pass

A clean rebuild of rizvisions.com as a macOS-inspired personal desktop.

## Deploy

Replace the files in the root of `rizvisions/portfolio` with these files and push to `main`. GitHub Pages will continue serving `rizvisions.com` through the included `CNAME` file.

## Included in v1

- macOS-style menu bar, desktop, dock, menus, context menu, window controls
- draggable/resizable/minimizable/maximizable windows
- draggable desktop icons
- local persistence for theme, wallpaper, icon/window positions, and Notes
- About, Selected Work, Photos, Parker, Career, Instagram chooser, TikTok, Spotify placeholder, Notes, Messages, Chicago Weather, Terminal, Resume, Trash
- live Chicago weather using Open-Meteo
- generated sound effects, keyboard shortcuts, and Easter eggs
